## What it is

jabol is a self-hostable link directory. You feed it a `links.json`, run a container,
and get a fast page with categorized + searchable bookmarks. An optional admin UI
lets you edit links from the browser and hide private links behind a sign-in.

## A 30-second example

```sh
docker run -d \
  -p 8080:8080 \
  -v "$PWD/links.json:/config/links.json" \
  -v "$PWD/data:/data" \
  -e JABOL_AUTH_SECRET="$(openssl rand -hex 32)" \
  stephanrandle/jabol:latest
```

Open [http://localhost:8080](http://localhost:8080), hit `/signup` to create the
first admin, then edit your links from `/admin`.
